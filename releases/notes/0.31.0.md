## 亮点
- 汇总 `0.30.0` 之后的全部更新，包含 `0.30.1` 草稿中的 Codex 会话识别与跳转修复
- 智能抑制新增「用户活跃时不自动展开」选项：近期使用键盘或鼠标时，审批和问题不会自动展开停靠或悬浮 Island；仍可点击或悬停查看，状态提示、声音及独立的完成通知设置继续生效

## 修复
- 修复 Claude 问题在跳过权限检查或会话自动审批时被自动放行、无法回答的问题，回答后不再重新出现多余审批卡片（#311、#316）
- 在非默认权限模式下，为受支持的 Claude 问题工具保留回答通道和足够的等待时间，同时覆盖本地、SSH 远程及原型安装；普通工具的 `questions` 参数不会被误判为提问（#316）
- 修复新旧应用实例重叠运行时，旧实例退出删除新实例监听 socket、导致 hook 无法继续送达的问题（#314）
- 让内置、8-bit 和导入音效包统一遵守各事件开关与提醒抑制设置（#312）
- 启动音预览遵守全局声音和临时静音设置，设置面板保持打开时也会即时刷新预览可用状态（#318）
- 修复 Qoder / Qoder CN 统计环境变量污染宿主识别的问题，结合真实终端、TTY、tmux、父进程及 Desktop 来源区分 Codex App 与 CLI，保留实际运行于 IDE 终端中的 CLI 会话
- 修正已确认错误的会话缓存和实时跳转信息，恢复 Codex 线程或终端跳转，避免残留的 Qoder 宿主信息再次覆盖修正结果
- 统一过滤标题生成、标题更新和建议生成辅助任务，覆盖 hook、快照、日志恢复及会话列表；正常 JSON 回复、根目录用户任务和用户接受建议后创建的任务仍正常显示

- 加强 socket 接管、问题回答、声音设置及智能抑制的回归覆盖

## Highlights
- Includes every update since `0.30.0`, including the Codex session identity and navigation fixes prepared in the `0.30.1` draft
- Adds an option under smart suppression to avoid automatic attention expansion while the user is active: recent keyboard or mouse activity suppresses approval and question popups in both docked and floating Island, while click/hover access, status cues, sounds, and separate completion notification settings remain available (#315)

## Fixes
- Keeps Claude questions answerable when permission checks or session tool approvals are bypassed, and prevents redundant approval cards from reappearing after an answer (#311, #316)
- Preserves the answer channel and a sufficiently long wait for supported Claude question tools in non-default permission modes across local, remote SSH, and prototype installations; ordinary tools with a `questions` argument are not intercepted (#316)
- Prevents an older app instance from removing a replacement instance's listening socket on exit, keeping hook delivery reachable during overlapping launches (#314)
- Makes built-in, 8-bit, and imported sound packs consistently honor event enablement and reminder suppression settings (#312)
- Makes startup sound previews honor global sound and temporary mute preferences, with availability updating while the settings panel remains open (#318)
- Prevents Qoder / Qoder CN statistics environment variables from contaminating host detection; combines actual terminal, TTY, tmux, parent-process, and Desktop evidence to distinguish Codex App from CLI while preserving genuine IDE-hosted CLI sessions
- Repairs confirmed incorrect cached and live navigation metadata, restores Codex thread or terminal routing, and prevents stale Qoder host information from overwriting those repairs
- Filters title generation, title updates, and suggestion helpers consistently across hooks, snapshots, rollout recovery, and session lists; preserves ordinary JSON replies, root-directory user tasks, and tasks created by accepting suggestions

## Improvements
- Expands both README languages with Pi and Oh My Pi integration details and mascot previews
- Strengthens regression coverage for socket takeover, question handling, sound preferences, and smart suppression

## Notes
- App version `0.31.0`, build `82`; covers `v0.30.0...v0.31.0`
- Existing session caches remain readable; ambiguous older records are repaired when new source evidence arrives
- Use the DMG for manual installation; ZIP, Sparkle updates, and Linux x86_64 / aarch64 remote bridge packages are also provided
- [Full changelog](https://github.com/erha19/ping-island/compare/v0.30.0...v0.31.0)
